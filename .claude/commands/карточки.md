---
description: Карточки вопрос–ответ для запоминания по теме. /карточки <предмет> [тема]
---
Аргументы: $ARGUMENTS
По готовым конспектам предмета/темы сделай карточки: каждое определение, формулировка теоремы/леммы, ключевая формула, условие применимости → одна карточка (класс .card из style.css: вопрос .q, ответ .a).
Всё с [!] — первым. Порядок: определения → теоремы → формулы → «в чём ловушка».
PDF: `_разборы/карточки_<тема>_<дата>.pdf`. Без плана. Отчёт: сколько карточек.
