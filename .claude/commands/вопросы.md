Аргументы: $ARGUMENTS (пусто = все предметы).
1. Собери все маркеры [?], [??], [пример], [док], [почему], [связь] из файла вопросы.md предмета и из всех исходных материалов, которые ещё не разобраны (см. .index.json, ключ "answered").
2. Для каждого — найди контекст через `grep -n` в `.source/text/*.md` и `.source/*.html` (не открывая PDF) и ответь по правилам маркеров из CLAUDE.md: [?] проще + пример; [??] с нуля, с предпосылок, 2 примера; [док] полное доказательство; [почему] мотивация и применение; [связь] связи с другими темами.
3. Собери один PDF `_разборы/разбор_вопросов_<дата>.pdf` по шаблону _templates/conspect.html: каждый вопрос — блок explain, цитата вопроса в заголовке блока.
4. В вопросы.md пометь отвеченные строки префиксом `[✓]` (не удалять). Обнови .index.json → "answered".
Без плана и подтверждений. Отчёт: сколько вопросов разобрано.
Сборка: HTML в `<предмет>/.source/<имя>.html` → `python3 _tools/build.py <предмет> <имя> --dir _разборы --pdf <имя PDF>`.
