description: Пересобрать существующий конспект с правкой. /переделай <предмет> <тема>: <что изменить>
---
Аргументы: $ARGUMENTS
Возьми .source/<тема>.html, внеси указанные правки точечно через Edit (не переписывая файл целиком и не трогая остальное), пересобери: `python3 _tools/build.py <предмет> <тема>` (имя PDF скрипт возьмёт из `.index.json`). Если правка касается рисунка — поправь спецификацию в `.source/fig/`; `build.py` сам прогонит `--check` и даст превью страницы — посмотри его. Без плана. Отчёт одной строкой.
