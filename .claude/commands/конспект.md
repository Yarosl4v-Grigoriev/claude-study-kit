Аргументы: $ARGUMENTS
- Пусто → обработать все необработанные материалы во всех предметах.
- Указан предмет → только он. Указана тема → только она.
Без плана, без вопросов, сразу PDF в _конспекты/. Правила — в CLAUDE.md (уже загружен); порядок действий — ниже,
отдельно SKILL.md читать не нужно.

## Порядок

1. **Найти новое:** `python3 _tools/prep.py pending [предмет]` (сам сверяет с `.index.json`; папки вручную не листать). Если указан конкретный предмет или тема — работать только с ними.

1а. **Расшифровать без картинок в основном диалоге** (раздел «Экономия токенов» в CLAUDE.md): для каждого исходника без `.source/text/<имя>.md` — `prep.py extract`, затем плитки расшифровывают субагенты (параллельно). Основной диалог картинки исходников не открывает.

2. **Сгруппировать необработанные файлы по темам.** Один конспект = одна тема. Если тема неочевидна — определить по заголовкам/первому абзацу.

3. **Прочитать расшифровки темы** (`.source/text/*.md`; учебник — только нужные фрагменты через `grep -n`), ранжируя по надёжности (лекция = материал преподавателя > учебник > аудио). Аудио и учебник используются для дополнения и проверки, не как основа.

4. **Собрать все маркеры** (`[?]`, `[??]`, `[!]`, `[пример]`, `[док]`, `[почему]`, `[связь]`) из материалов темы. Для каждого запланировать блок «Разбор» в нужном месте конспекта.

5. **Написать содержание** прямо в `<предмет>/.source/<тема>.html` по шаблону `_templates/conspect.html`:
   - блоки `def` / `lemma` / `theorem` / `axiom` / `proof` / `example` / `important` / `explain` — по классам из style.css;
   - формулы в LaTeX (MathJax подключён в шаблоне);
   - рисунки — пересозданный SVG инлайном (перед этим прочитать `_tools/FIGURES.md`). Графики функций и схемы — только через `_tools/figures.py`
     (спецификация → `<предмет>/.source/fig/<тема>.json`, прогнать `--check`, SVG вставить в `<figure>`).
     Правила «Визуализация обязательна» из `_tools/FIGURES.md`: рисунок к каждому понятию с геометрическим смыслом,
     минимум один на раздел `h2`. Текст и определения при этом не сокращать;
   - расхождения источников — блок `note` с указанием, что взято.

6. **Собрать PDF одной командой** (не собирать вручную по шагам):
   `python3 _tools/build.py <предмет> <тема> --pdf <лекция|семинар>_<ГГГГ-ММ-ДД>_<тема>.pdf --sources <исходник> ...`
   (имя — правило 4 CLAUDE.md; `--fig <имя>`, если спецификация рисунков названа не как тема).
   Скрипт сам: `--check` рисунков, подстановка `<!--fig:…-->`/`<!--svg:…-->`, печать в `_конспекты/`, проверка
   сырого LaTeX, превью страниц с рисунками в `.source/_preview/`, запись в `.index.json`.

7. **Посмотреть превью из вывода скрипта** (только эти PNG): график совпадает с `--check`, подписи не наезжают,
   рисунок не разрезан. Строки `!` в выводе — исправить. Ошибка → правка (Edit) → тот же `build.py` без `--sources`.

8. **Отчёт пользователю — 3–5 строк:** что собрано, сколько маркеров разобрано, что осталось неполным. Без пересказа содержания.

## Не делать
- Не показывать план, не спрашивать «продолжать?».
- Не оставлять md/html вне `.source/`.
- Не придумывать доказательства и факты.
- Не переписывать style.css.
- Не рисовать графики функций от руки (Безье/«на глаз»).
- Не открывать в основном диалоге PDF/фото исходников и готовые PDF целиком — только текст (`.source/text`, `.source/*.html`).
