# ClaudeStudy — конспекты по математике силами Claude Code

**Из фото лекций, раздаток и глав учебника — строгий PDF-конспект с теоремами, доказательствами,
разобранными примерами и точными графиками. Одной командой.**

![Страница демо-конспекта](examples/preview.png)

Полный пример: [`examples/пример_конспекта.pdf`](examples/пример_конспекта.pdf) — предел последовательности,
три рисунка из `figures.py`, блоки «Разбор» и «Важно для экзамена».

---

## Зачем это

На технических специальностях материал по одной теме разбросан по четырём местам: записи с лекции, раздатка
преподавателя, учебник и запись аудио. Собирать из этого нормальный конспект долго, а спрашивать у чат-бота
«объясни тему» — значит получить пересказ своими словами, с выдуманными формулировками и графиками «на глаз».

ClaudeStudy превращает Claude Code в **ассистента-конспектора с жёсткими правилами**. Цели проекта:

1. **Конспект по твоим материалам, а не «по мотивам».** Формулировки определений и теорем берутся как в источнике.
   Если доказательства в материалах нет, Claude так и пишет, а не придумывает его.
2. **Разбирать именно то, что непонятно тебе.** Ставишь `[?]` у непонятного места в своих записях — в конспекте
   сразу после него появляется блок «Разбор» с объяснением и примером.
3. **Готовить к экзамену, а не только к чтению.** Из конспектов делаются карточки, задачи с решениями и шпаргалки.
4. **Одинаковое качество каждый раз.** Единый стиль PDF, единые имена файлов, реестр обработанного.
   Повторный запуск обрабатывает только новое.
5. **Экономно расходовать лимит.** Каждый исходник «читается глазами» один раз, дальше — только текст.
   На замере пиковый контекст уменьшился в 2,3 раза, а токенов на конспект стало на ~21% меньше (подробности ниже).

## Чем отличается от «просто спросить ChatGPT»

| | Обычный чат | ClaudeStudy |
|---|---|---|
| Источник | общие знания модели | **твои** лекции, раздатки, учебник; приоритет: лекция > учебник > аудио |
| Формулировки | «улучшенные» и пересказанные | дословно как в источнике; расхождения источников отмечены явно |
| Доказательства | иногда выдуманные | из материалов или стандартное с пометкой источника; иначе честное «не приведено» |
| Графики | кривые «на глаз» (у $1/x$ может появиться одна ветвь через ноль) | **вычисленные по точкам** через `figures.py` и проверенные `--check` перед вставкой |
| Непонятные места | надо формулировать вопрос заново | маркер `[?]` прямо в записях → блок «Разбор» на своём месте |
| Результат | текст в чате | PDF с цветными блоками: определение / теорема / доказательство / пример |
| Память | каждый раз заново | `.index.json`: что уже обработано и в какой PDF вошло |
| Подготовка к экзамену | вручную | `/карточки`, `/задачи`, `/шпаргалка` по готовым конспектам |
| Расход токенов | фото лекций висят в диалоге и перечитываются на каждом шаге | фото расшифровываются один раз отдельным субагентом, дальше работа идёт с текстом |

## Ключевые возможности

### 📄 Конспект одной командой
`/конспект матанализ` читает новые материалы, группирует их по темам и собирает PDF:
определения → леммы и теоремы → доказательства → примеры с числами. Формулы в LaTeX (MathJax),
блоки раскрашены по типу, сверху легенда.

### 📈 Точные рисунки: `figures.py`
Генератор SVG на чистом Python, без зависимостей. Графики **никогда не рисуются от руки**: кривая строится
по вычисленным значениям $f(x)$ и сама рвётся в точках разрыва.

| Тип | Для чего |
|---|---|
| `plot` | графики функций, асимптоты, выколотые точки, площади под кривой |
| `numberline` | промежутки, окрестности, решения неравенств |
| `sequence` | члены последовательности, полоса $a\pm\varepsilon$, отметка $N(\varepsilon)$ |
| `venn` | операции над множествами, законы де Моргана |
| `mapping`, `chain` | отображения, инъекции/сюръекции, композиция |
| `flow` | ход доказательства, цепочки эквивалентностей |

Правило проекта — минимум один рисунок на раздел, рисунки **добавляются** к тексту, а не заменяют его.
Перед вставкой `figures.py spec.json --check` печатает ветви, монотонность, знаки и значения, чтобы сверить их
с математикой. После сборки Claude смотрит страницы PDF и проверяет, что подписи не наезжают, а рисунок не разрезан.

### 🏷 Маркеры прямо в твоих записях

| Маркер | Что сделает Claude |
|---|---|
| `[?]` | объяснит проще, другими словами, с примером |
| `[??]` | объяснит с нуля, с предпосылками, минимум 2 примера |
| `[!]` | вынесет в блок «Важно для экзамена» и добавит в шпаргалку |
| `[пример]` | добавит разобранный пример с числами |
| `[док]` | даст полное доказательство (или честно напишет, что его нет) |
| `[почему]` | объяснит мотивацию: зачем понятие и где применяется |
| `[связь]` | покажет связь с другими темами предмета |

### 🧠 Подготовка к экзамену
Карточки для активного вспоминания, задачи с полными решениями (40% на определения, 40% на вычисления,
20% на доказательства) и двухколоночная шпаргалка на 1–2 страницы A4.

### 🇬🇧 Английский: свой контур
Отдельные правила для языка: проверка **твоей** попытки домашки вместо готовых ответов, «ответ + правило»
к каждому заданию, личный словарь с интервальным повторением и учёт повторяющихся ошибок,
который подмешивает слабые места в упражнения.

### 💸 Экономия токенов
Фото досок, сканы и готовые PDF больше не попадают в основной диалог. `_tools/prep.py` готовит исходники:
текстовые PDF и .docx переводит в текст бесплатно, рукописи режет на плитки, которые один раз расшифровывает
субагент. Подробности и цифры — в разделе [«Сколько это стоит в токенах»](#сколько-это-стоит-в-токенах).

### 🔄 Синхронизация с iPad (macOS, опционально)
Пишешь лекцию в Apple Notes или Freeform с меткой `Матан-лекция 22.09.26`, а `/синхрон` сам выгружает её
в PDF в папку нужного предмета.

## Команды (навыки)

| Команда | Что делает |
|---|---|
| `/конспект [предмет] [тема]` | собирает PDF-конспект по новым материалам |
| `/вопросы [предмет]` | отвечает на все маркеры из `вопросы.md` и материалов → PDF в `_разборы/` |
| `/объясни <что>` | быстрое объяснение в чате: суть, строгая формулировка, пример, типичная ошибка |
| `/карточки <предмет> [тема]` | карточки «вопрос–ответ» |
| `/задачи <предмет> <тема> [n]` | тренировочные задачи с решениями и типичными ошибками |
| `/шпаргалка <предмет> [тема]` | плотная выжимка к экзамену |
| `/сверка <предмет> <тема>` | ищет пропуски и расхождения конспекта с исходниками и исправляет их |
| `/переделай <предмет> <тема>: …` | точечная правка готового конспекта, включая рисунки |
| `/статус` | таблица: что обработано, что ждёт, сколько открытых вопросов (считает скрипт, на Haiku) |
| `/дз [тема]` | английский: проверка и разбор домашки (текст или фото) |
| `/слова [тема\|повтор]` | английский: словарь и упражнения на повтор |
| `/синхрон [--redo]` | macOS: выгрузка помеченных заметок из Notes/Freeform |

Основной навык `math-conspect-builder` (`.claude/skills/`) описывает порядок сборки конспекта. Правила разложены так,
чтобы в каждую сессию грузилось только нужное:

| Файл | Что внутри | Когда загружается |
|---|---|---|
| [`CLAUDE.md`](CLAUDE.md) | тон, маркеры, точность, имена файлов, экономия токенов | всегда |
| [`_tools/FIGURES.md`](_tools/FIGURES.md) | что и как рисовать, `--check`, визуальная проверка | только при работе с рисунками |
| [`английский/CLAUDE.md`](английский/CLAUDE.md) | домашка, словарь, интервальный повтор | только при работе с английским |
| `.claude/commands/синхрон.md` | правила выгрузки из Notes/Freeform | только при `/синхрон` |

Команды на эти файлы ссылаются и не переопределяют их. Рутинные команды заранее привязаны к моделям подешевле:
`/статус` и `/синхрон` — Haiku; `/объясни`, `/карточки`, `/шпаргалка` — Sonnet.

### Скрипты

| Скрипт | Что делает |
|---|---|
| `_tools/prep.py pending [предмет]` | список новых исходников (не вошедших в `.index.json`) и их состояние |
| `_tools/prep.py extract <файл>` | текстовый PDF / .txt / .docx → `.source/text/<имя>.md`; рукопись (Freeform, .pages, фото) → плитки 1400×1400 для расшифровки |
| `_tools/prep.py status` | таблица для `/статус` без участия модели |
| `_tools/figures.py spec.json [--check \| -o dir \| --inline src out]` | SVG-рисунки по спецификации и их проверка |
| `_tools/new_subject.sh <предмет> …` | создаёт папку предмета со всей структурой |
| `_tools/sync_all.sh [--redo]` | выгрузка из Notes и Freeform (macOS) |
| `_tools/make_app.sh` | собирает `Синхронизация.app` для запуска двойным кликом |

## Установка

**Нужно:**
- [Claude Code](https://claude.com/claude-code) — десктоп-приложение или CLI, с подпиской Claude или API-ключом;
- Python 3 — для `figures.py` и скриптов;
- Google Chrome **или** `weasyprint` — печать в PDF;
- `pdftoppm` и `pdftotext` (`brew install poppler`) — визуальная проверка страниц и извлечение текста из PDF;
- Pillow (`pip install pillow`) — нарезка рукописей на плитки;
- интернет при сборке PDF: формулы рендерит MathJax с CDN.

```bash
git clone https://github.com/Yarosl4v-Grigoriev/claude-study-kit.git
cd claude-study-kit
_tools/new_subject.sh матанализ алгебра линал
```

Открой папку в Claude Code, положи материалы, например в `матанализ/Конспект_с_пада/`, и напиши `/конспект матанализ`.

Рекомендуется отключить в папке проекта плагины claude.ai, которые для учёбы не нужны: их описания загружаются
в каждую сессию. Создай `.claude/settings.local.json` (действует только на твоём компьютере):

```json
{
  "syncClaudeAiPlugins": false
}
```

Коннекторы claude.ai (Gmail, Drive и т. п.) в десктоп-приложении этим файлом не отключаются: ключ
`disableClaudeAiConnectors` там не срабатывает (проверено). Их выключают в поле ввода: **«+» → Connectors**.

> Модель: для рутины хватает Sonnet, для сложных доказательств лучше Opus.
> Режим разрешений: удобнее «accept edits» или auto mode. Полный обход разрешений включай только если
> папка изолирована.

Папки предметов и всё, что в них лежит, исключены в `.gitignore`: личные материалы в репозиторий не попадут.

## Сколько это стоит в токенах

Почти весь расход — не ответы модели, а **повторное чтение контекста**: на каждом шаге модель заново читает весь
диалог. Поэтому дороже всего то, что раздувает диалог: картинки, большие файлы, длинные сессии.

**Замер на реальных сессиях автора** (Sonnet, `/конспект` по алгебре с рукописными досками Freeform):

| | До оптимизации (26.09) | После (01.10) |
|---|---|---|
| Что собрано | 3 конспекта за одну сессию | 1 конспект, 2 источника |
| Запросов к модели | 39 | 18 + 4 у субагента-расшифровщика |
| Токенов всего | 7,35 млн | 1,93 млн (1,67 основной диалог + 0,26 субагент) |
| Токенов на один конспект | ~2,45 млн | **1,93 млн** (−21%) |
| Пиковый контекст | 262 тыс. | **113 тыс.** (в 2,3 раза меньше) |
| Картинок в основном диалоге | 14 | 4 — только проверка готовых рисунков |
| Рисунки по `figures.py` | не было правила | 4 рисунка, проверены `--check` и по страницам PDF |

Главный эффект — **контекст больше не разрастается**: картинки исходников живут только у субагента, а основной
диалог работает с текстом. Сессия не упирается в предел контекста, и длинная тема не дорожает с каждым шагом.

Честная оговорка: если взвесить токены по цене (ответ модели дороже чтения из кэша), один конспект «после» стоит
примерно на четверть **дороже**, чем «до». Причина — больше содержания: обязательные рисунки с проверкой, а
одна тема в отдельной сессии не делит стартовые расходы с другими темами. Если по сравнению с прошлым экономить
нужно сильнее, собирай 2–3 темы одного предмета подряд в одной сессии.

Для других команд это пока **оценка**, а не замер:

| Задача | До (замер) | После (оценка) | За счёт чего |
|---|---|---|---|
| `/шпаргалка` по 2–3 конспектам | ~2 млн (20 страниц PDF картинками) | ~0,5–0,8 млн | читается `.source/*.html`, а не PDF |
| `/объясни` | ~0,6 млн | ~0,25 млн | `grep` по тексту, модель Sonnet |
| `/статус` | не замерялось | ~0,05 млн | таблицу считает `prep.py`, модель Haiku |

Стартовый контекст сессии — около 65 тыс. токенов (до оптимизации 62–81 тыс.). В основном это системная часть
Claude Code, которую проект не контролирует.

Бо́льшая часть этих токенов — чтение из кэша, оно заметно дешевле обычного ввода. Но на лимит подписки влияет
именно объём, поэтому правило простое: **одна тема — одна сессия**. Закончил тему — начни новый чат.

## Настройка под себя

- **Тон и уровень** — раздел «Аудитория и тон» в `CLAUDE.md`.
- **Внешний вид** — `_templates/style.css`: цвета блоков заданы переменными в `:root`; палитра `figures.py` с ними согласована.
- **Другой предмет со своими правилами** — по образцу раздела про английский в `CLAUDE.md`.
- **Метки для синхронизации** — `_tools/subjects.json`.

## Синхронизация с Notes и Freeform (macOS)

1. Начинай заголовок заметки или доски с метки `<Предмет>-<лекция|семинар>`, например `Матан-лекция 22.09.26`.
2. Запусти `/синхрон` или `_tools/sync_all.sh`. PDF попадут в `<предмет>/Конспект_с_пада/`, экспорт идёт через Pages.
3. По желанию: `_tools/make_app.sh` соберёт `Синхронизация.app`, которая запускает синхронизацию двойным кликом.

Ограничения: нужны macOS и Pages. Freeform экспортируется через интерфейс: запускающему приложению нужен
«Универсальный доступ». Скрипт ищет пункты меню по **русским** названиям, поэтому при другом языке системы поправь
строки в `_tools/sync_freeform.py`. Во время экспорта ~15 секунд на доску не трогай мышь.

## Честное использование

- **ИИ ошибается.** Сверяй конспект с источниками (`/сверка` помогает, но не гарантирует), особенно перед экзаменом.
- **Авторские права.** Лекции, раздатки и учебники принадлежат их авторам. Конспекты для себя делать можно;
  публикуя их, пересказывай своими словами и не копируй чужие материалы.
- **Академическая честность.** `/дз` проверяет твою попытку и объясняет правила, чтобы ты учился.
  Не сдавай сгенерированное как свою работу.
