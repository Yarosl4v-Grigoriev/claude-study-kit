Все правила формата, маркеров, точности и экономии — в `CLAUDE.md`. Здесь только порядок действий.

## Порядок

1. **Прочитать `.index.json`** (если нет — создать пустой `{}`) и определить, какие файлы в подпапках предмета ещё не обработаны. Если указан конкретный предмет или тема — работать только с ними.

2. **Сгруппировать необработанные файлы по темам.** Один конспект = одна тема. Если тема неочевидна — определить по заголовкам/первому абзацу.

3. **Прочитать все материалы темы**, ранжируя по надёжности (лекция = материал преподавателя > учебник > аудио). Аудио и учебник используются для дополнения и проверки, не как основа.

4. **Собрать все маркеры** (`[?]`, `[??]`, `[!]`, `[пример]`, `[док]`, `[почему]`, `[связь]`) из материалов темы. Для каждого запланировать блок «Разбор» в нужном месте конспекта.

5. **Написать содержание** прямо в `<предмет>/.source/<тема>.html` по шаблону `_templates/conspect.html`:
   - блоки `def` / `lemma` / `theorem` / `axiom` / `proof` / `example` / `important` / `explain` — по классам из style.css;
   - формулы в LaTeX (MathJax подключён в шаблоне);
   - рисунки — пересозданный SVG инлайном. Графики функций и схемы — только через `_tools/figures.py`
     (спецификация → `<предмет>/.source/fig/<тема>.json`, прогнать `--check`, SVG вставить в `<figure>`).
     Правила «Визуализация обязательна» из CLAUDE.md: рисунок к каждому понятию с геометрическим смыслом,
     минимум один на раздел `h2`. Текст и определения при этом не сокращать;
   - расхождения источников — блок `note` с указанием, что взято.

6. **Сконвертировать в PDF** одним шагом (Chrome headless / weasyprint — что есть в системе; если ничего нет, установить weasyprint и запомнить это в `.index.json` под ключом `"pdf_engine"`). Результат — `<предмет>/_конспекты/<лекция|семинар>_<ГГГГ-ММ-ДД>_<тема>.pdf` (правило 4 CLAUDE.md).

6а. **Посмотреть рисунки в готовом PDF** (`pdftoppm -r 70 -png` → прочитать PNG → удалить): график совпадает с `--check`,
   подписи не наезжают, рисунок не разрезан. Ошибка — исправить спецификацию и пересобрать PDF.

7. **Обновить `.index.json`**: для каждого исходного файла — путь к PDF, дата, тема.

8. **Отчёт пользователю — 3–5 строк:** что собрано, сколько маркеров разобрано, что осталось неполным. Без пересказа содержания.

## Не делать
- Не показывать план, не спрашивать «продолжать?».
- Не оставлять md/html вне `.source/`.
- Не придумывать доказательства и факты.
- Не переписывать style.css.
- Не рисовать графики функций от руки (Безье/«на глаз»).
